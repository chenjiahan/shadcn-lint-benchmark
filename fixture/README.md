# fixture-rich

The eleven components a fresh `shadcn init` project ships with (base-nova:
avatar, badge, button, card, dropdown-menu, input, label, select,
separator, table, tabs) and its `globals.css`, copied from a project
created by the CLI. Used by the neutral battery, where tasks assemble
primitives into pages; the three-component `fixture/` stays as the
baseline for the temptation suite.
